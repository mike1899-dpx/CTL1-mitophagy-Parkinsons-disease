# CTL1-mitophagy-Parkinsons-disease
Analysis code accompanying the Science Advances manuscript on CTL1-mediated mitophagy and dopaminergic neuroprotection.

# Single-cell RNA-seq analysis
This repository contains an R script used for exploratory single-cell RNA-seq analysis in relation to the manuscript 

## Contents
`Monocle3.DPX.R`: Seurat-based processing and visualization, examination of **SLC44A1** expression across annotated groups, and exploratory trajectory-analysis code using Monocle-related functions.

## Software
The script uses R and packages including Seurat, dplyr, ggplot2, patchwork, harmony, monocle3, ggpubr, SCP, tidydr, and other packages referenced in the script. It also contains a section using Monocle 2 functions.
